# Domain documentation

This is a single-context repository.

Before exploring a domain area, read the root `CONTEXT.md` if it exists and the relevant records in `docs/adr/`. If neither exists, continue without creating them upfront; add them when a domain term needs definition or a consequential decision needs recording.

Use the glossary's terms in issues, tests, and implementation. Surface conflicts with an existing ADR instead of silently overriding it.

# Recorded real-data runs

See [the test report](../2026-10-16-real-data-browser-report.md) for the precise
setup, measured results, limitations, and source attribution.

The videos, screenshots, and traces contain derived OpenSanctions material
(CC BY-NC 4.0) and GLEIF material (CC0). The repository code licence does not
replace those source licences. Source fields remain visible in the application.

Each attempt has a video, a final screenshot, and a Playwright trace. The run
summary records their SHA-256 hashes. Trace archives are for local inspection
with Playwright's `show-trace`; they contain actual API responses from the
dedicated local real-data workspace.
